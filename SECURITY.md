# Security policy

Open Origin is pre-alpha: nothing is deployed, and only the `main` branch is maintained.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/Tienda-Universx/open-origin/security/advisories/new).
Do not open a public issue for a vulnerability.

Include what is affected, how to reproduce it, and its impact. The maintainer will acknowledge the
report and keep you informed while it is fixed. There is no bug bounty.

## Scope

In scope: the code, workflows, and configuration in this repository. Leaked credentials count too:
report them even if you are not sure they are valid.
